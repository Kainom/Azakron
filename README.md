# Azakron

AZACOM is a simple mobile application for managing notes and tasks. The project is developed in **Kotlin for Android** and focuses on providing a lightweight and straightforward experience for quickly creating and organizing personal notes.

The application features a minimalistic user interface with simplified layouts and modal-based note creation. Users can easily create, update, delete, and list notes, performing basic CRUD operations in an intuitive way.

AZACOM is designed for quick and practical note-taking, similar to a small personal notebook. It is ideal for storing everyday information such as shopping lists, recipes, reminders, or any short notes that need to be quickly accessed and managed.

The main goal of this project is simplicity, offering a clean interface and fast interaction for users who just need a basic and efficient way to manage their notes.
